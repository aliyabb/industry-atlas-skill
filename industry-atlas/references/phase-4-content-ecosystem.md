# Phase 4 — Content ecosystem

**Goal:** a map of 100+ sources that shape the industry conversation, why they work, and how the user can learn from them or build a presence.

## Sources by platform

| File | Target (standard) | Columns |
|---|---|---|

Audience tiers: **S** <10K · **M** 10–100K · **L** 100K–1M · **XL** 1M+, marked ⚠️ unless taken from a dated primary source. Links must come from search results or official pages.

## Content-Classification.md

Five types of content:

| Type | Goal | Signs | Success metrics |
|---|---|---|---|
| **R — Reach** | New people | Strong opinions, debates, failures, predictions | Impressions, shares, new followers |
| **S — Subscription** | Regular return | Digests, trackers, weekly roundups | Subscribers, open rate, retention |
| **Sv — Saveable** | Long-term value | Step-by-step guides, diagrams, templates, frameworks | Saves, forwards, search traffic |
| **C — Conversion** | Action (lead, sale, interview) | Case studies with numbers, demos, comparisons, calculators | Clicks, leads, sign-ups |
| **PB — Personal brand** | Trust in a person | Stories, mistakes, reflections, principles | Comments, DMs, invitations |

Add examples from this industry for each type, a mix by goal (audience growth, job search, B2B company, B2C company), and a format × type matrix.

## Engagement-Patterns.md

1. **12 patterns** that repeatedly work in this industry (for example strict regularity, news plus a thesis within 24 hours, numbers from primary sources, failure breakdowns, visual explainers, memes, content → community → events flywheel, repurposing across platforms, founder as media, quantified case studies, tools instead of text, early capture of a new topic), each with who uses it and why it works.
2. **Saturated content** and better alternatives.
3. **Content gaps** (opportunities for an author).
4. **A 12-week personal brand plan** for the user's purpose (career or founder), week by week.
